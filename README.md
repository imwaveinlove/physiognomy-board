# 관상 분류기 @whitecotchi

캐릭터 사진을 넣으면 얼굴을 분석해서 **동물상**과 **^^ / ㅍㅍ상** 두 축으로 자동 분류해 주는 페이지.

## 쓰는 법

1. `index.html`을 브라우저로 열기
2. 사진을 드래그해서 놓기 (여러 장 한 번에 가능 · `Ctrl+V` 붙여넣기도 됨)
3. 자동으로 분석해서 보드에 배치 — 이름은 파일명으로 들어감
4. 결과가 어긋나면 얼굴을 다른 칸으로 **끌어다 놓으면** 바로 고쳐짐 (얼굴 클릭 → 모달에서 버튼으로도 가능)

얼굴을 클릭하면 뜨는 창에서:

- **이름**: 위쪽 이름칸을 그냥 눌러서 고쳐 쓰면 됨 (바로 저장)
- **사진 위치/크기**: 동그란 사진 위에서 **휠로 확대·축소**, **끌어서 위치 이동** (＋/− 버튼도 있음). 얼굴이 화면에 꽉 차게 맞추면 판정도 정확해짐 — 크롭을 바꾸면 잘라낸 영역으로 **자동 재분석**되고, 직접 지정해 둔 분류는 덮어쓰지 않음
- **삭제**: 삭제 버튼을 두 번 누르면 삭제 (실수 방지, 3초 지나면 해제)

## 분류

| 축 | 분류 |
|---|---|
| 표정 | `ㅍㅍ상` · `^^상` |
| 동물상 | 🐶 강아지상 · 🐱 고양이상 · 🦊 여우상 · 🐻 곰상 |

탭으로 두 축을 번갈아 볼 수 있고, 칩 오른쪽 위 뱃지에 반대 축 분류가 같이 표시됨.

## 자동 판정 방식

브라우저에서 외부 라이브러리 없이 돌아가는 얼굴 인식 AI는 없고, 실사 얼굴 인식 모델은 일러스트 얼굴에 잘 맞지 않는다.
그래서 **이미지 픽셀을 직접 재는 방식**으로 구현했다.

1. HSV로 변환해 살색 픽셀 마스크를 만들고, 연결 성분 중 가장 크고 중앙에 가까운 덩어리를 얼굴로 잡음
2. 얼굴 박스 안에서 행별 폭을 재서 **얼굴 세로/가로 비율**, **턱선 테이퍼**(아래쪽 폭 / 중간 폭) 계산
3. 얼굴 위쪽 밴드에서 좌우 어두운 덩어리를 눈으로 잡아 **눈 가로세로비**, **눈 면적**, 윗선 기울기 회귀로 **눈꼬리 각도** 계산
4. 얼굴 아래쪽 밴드에서 가장 큰 어두운 연결 성분을 입으로 잡고, 윗선의 **양끝 높이 − 가운데 높이**로 입꼬리 곡률 계산
5. 위 값들을 정규화해 동물상 4종에 가중합 → softmax로 비율 산출
6. 입꼬리 곡률(주), 입 벌어짐, 전체 밝기/채도, 눈매 납작함을 합쳐 `tanh`로 **^^ 지수 0~100** 산출

모달의 "측정값" 칸에서 실제로 잰 숫자를 그대로 볼 수 있다.

### 정확도에 대해

기계가 픽셀만 보고 재는 값이라 사람이 보는 것만큼 정확하지 않다. 특히:

- 앞머리가 눈을 덮거나, 얼굴이 크게 기울어졌거나, 배경이 살색에 가까우면 얼굴 검출이 흔들림
- 눈이 거의 동그란 경우 눈꼬리 각도 신호가 약해짐 (원은 회전시켜도 윗선 기울기가 잘 안 변함)
- 입이 아주 작거나 머리카락에 가려지면 입꼬리를 못 재고, 이때는 밝기 위주로 판정 (모달에 "얼굴 인식 약함" 표시)

그래서 드래그로 고치는 기능이 기본으로 들어가 있다.

## 구현 메모

- 외부 라이브러리 없는 단일 HTML 파일
- 업로드 이미지는 최대 변 420px JPEG **원본 1장**으로 저장하고, 크롭은 `{cx, cy, s}` 값으로만 들고 있음
  (칩·모달은 `background-size`/`background-position`으로, 분석과 PNG 내보내기는 `drawImage`의 소스 사각형으로 같은 값을 씀)
- 분석은 크롭을 256px로 뽑아 160px로 줄여서 수행
- `prompt()`/`confirm()`은 쓰지 않음 — 크롬이 "추가 대화상자 표시 안 함"을 켜면 조용히 무시돼서 버튼이 먹통이 됨.
  이름은 인풋 직접 편집, 삭제는 2단계 버튼으로 처리
- `localStorage` 키: `gwansang-wc-v2`
- PNG 내보내기는 현재 보고 있는 탭 기준 (`^^/ㅍㅍ`는 2단 대비 레이아웃, `동물상`은 4단 스택)
